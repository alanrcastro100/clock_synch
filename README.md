# Exercício de construção de um sistema básico de sincronização com algoritmo de Berkeley.

### **Para rodar o sistema:**

#### 1. **Instalar e iniciar o Venv:**
   Instalar:

   ```bash
   python -m venv .venv
   ```
   Inicializar:

   - Windows:
      ```bash
      .venv\Scripts\activate.bat
      ```
   - Linux:
      ```bash
      source .venv/bin/activate
      ```
#### 2. **Instalar Colorama:**
   ```bash
   python -m pip install colorama
   ```

### 3. **Executar o sistema**
   ```bash
   python __main__.py
   ```
